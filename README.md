# Баланс белого (White Balance)

Десктопное приложение на **C++ / QML / qmake** для автоматической коррекции баланса белого в видео.

## Ключевая особенность

Коррекция вычисляется **один раз по эталонному кадру** (в момент нажатия «Применить»), превращается в таблицу поиска (LUT) и дальше применяется к каждому кадру без изменений. Оттенки не «плавают» и не смещаются по мере воспроизведения видео.

## Алгоритмы

| Алгоритм | Параметры |
|---|---|
| Серый мир (Grey World) | сила коррекции |
| Белое пятно (White Patch) | сила коррекции |
| Идеальный отражатель (Perfect Reflector) | сила, % верхних ярких пикселей |
| Оттенки серого (Shades of Grey) | сила, показатель Минковского p |
| Серая граница (Grey Edge, van de Weijer et al.) | сила, p, порядок производной (0/1/2) |

## Сборка

Требования: Qt 5.12+ (модули quick, qml, widgets), OpenCV 4, qmake.

```bash
qmake WhiteBalance.pro
make
./WhiteBalance
```

## Структура

- `main.cpp` — точка входа, регистрация `VideoProcessor` в QML-контексте, рабочий поток
- `VideoProcessor.h/.cpp` — чтение видео через OpenCV, воспроизведение по таймеру, фиксированная LUT-коррекция
- `WhiteBalance.h/.cpp` — алгоритмы вычисления множителей каналов (B, G, R) и построение LUT
- `qml/main.qml` — интерфейс: открытие видео, выбор алгоритма, настройки, Apply/Сброс, плеер

## Как пользоваться

1. «Открыть видео…» — выбрать файл (mp4, avi, mkv, mov, webm, m4v, wmv).
2. Перемотать на репрезентативный кадр (тот, где есть нейтральный объект — серый/белый).
3. Выбрать алгоритм, настроить параметры.
4. «Применить к видео» — множители фиксируются на всё видео.
5. Играть / пауза / перемотка — коррекция остаётся постоянной до следующего «Применить».
